# 🎮 Catálogo de Jogos – Supabase + WeWeb  

## 📌 Descrição do Projeto  
Este projeto é um **Catálogo de Jogos** desenvolvido como trabalho da disciplina(**Projeto de Banco de Dados**), integrando **Supabase (back-end e banco de dados)** e **WeWeb (front-end)**.  

O sistema permite o **cadastro e listagem. Edição e exclusão de jogos(Em breve!!!)**, possibilitando ao usuário gerenciar um catálogo completo.

## 🗂️ Modelo Lógico do Banco de Dados  
O banco foi projetado em conformidade com a **3ª Forma Normal** e conta com tabelas relacionadas.  
O diagrama está disponível em:  
📄 `Diagrama DER/Catálogo de Jogos.drawio.pdf`  

Além disso, foram implementados:  
- ✅ **Tabelas** para gerenciamento dos jogos  
- ✅ **View** para facilitar consultas  
- ✅ **Função** para calcular informações adicionais (ex.: total gasto pelo usuário)  

---

## 🛠️ Funcionalidades da Aplicação  
- Cadastro de jogos (nome, gênero, preço, data de lançamento)  
- Listagem de todos os jogos cadastrados  
- Edição e exclusão de jogos existentes(Em breve!!!)
- Função para cálculo do **total gasto** pelo usuário  
- View no banco para consultas otimizadas

## 🚀 Tecnologias Utilizadas  
- **Supabase** → Banco de dados PostgreSQL, criação de tabelas, views e funções.
- **WeWeb** → Desenvolvimento front-end low-code, integrado ao Supabase
